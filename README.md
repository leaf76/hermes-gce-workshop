# Hermes Agent GCE Workshop

Single-file bilingual workshop deck for running Hermes Agent on Google Compute Engine and connecting it to Telegram or Discord.

## View

Open `ppt/index.html` locally, or publish this repository with GitHub Pages from the `main` branch root.

## Controls

- `Left` / `Right`: navigate slides
- `L`: switch language
- `N`: toggle speaker notes
- `B`: toggle static mode
- `ESC`: open slide index

## Security

The deck uses redacted placeholders only. Do not commit real API keys, bot tokens, OAuth credentials, or production secrets.
